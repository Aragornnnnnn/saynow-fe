# Planning

## 시나리오 목록

| 카테고리 | 쉬운 | 어려운 |
| --- | --- | --- |
| 카페 | 아메리카노 주문 | 커스텀 음료 주문 (사이즈, 샷 추가 등) |
| 공항 | 탑승구 위치 물어보기 | 수하물 분실 신고하기 |
| 호텔 | 체크인 하기 | 룸 컴플레인 하기 (에어컨 고장 등) |
| 식당 | 메뉴 추천 받고 주문하기 | 알레르기 재료 확인하고 주문하기 |
| 택시 | 목적지 말하기 | 기사가 못 찾아서 전화로 길 설명하기 |

시나리오 상세 내용 (질문 흐름, 클리어 기준 등)은 백엔드 DB에서 관리.

---

## 페이지 1 — 시나리오 선택

### 레이아웃
- 전체 시나리오를 2열 그리드로 표시
- 상단 카테고리 버튼으로 필터링
- 기본: 전체 표시

### 시나리오 카드
- 제목
- 이모지 아이콘
- 난이도 라벨 (쉬움 → 초록 / 어려움 → 주황)

### 모달 (카드 클릭 시)
- 시나리오 제목
- 상황 설명
- 달성 목표 (ex. 아이스 아메리카노 주문에 성공하세요)
- 시작 버튼 → 대화 페이지로 이동

### 기타
- 클리어 표시 없음 (로그인 없음)

---

## 페이지 2 — 대화

### 레이아웃
- 배경: 시나리오별 GPT 생성 이미지
- 왼쪽 상단: 나가기 버튼 (확인 모달)
- 상단: 외국인 대사 텍스트
- 하단: 마이크 버튼 + STT 자막 (반투명 배경)
- 하단: 다음 질문 버튼

### 대화 흐름
```
진입 → 외국인 대사 TTS 자동 재생
→ 마이크 버튼 누름 → 녹음 시작 + 실시간 STT 자막
→ 마이크 버튼 다시 누름 → 녹음 종료 → STT 확정
→ "다음 질문" 버튼 활성화
→ 버튼 누르면 다음 외국인 대사 TTS 재생
→ 최대 5회 반복
→ 5회 완료 or AI 클리어 판정
→ "다음 질문" 버튼 → "결과 보기" 버튼으로 교체
→ 누르면 피드백 페이지로 이동
```

### 기타
- 발화 시작까지 걸린 시간 기록 (마이크 활성화 ~ 녹음 시작)
- 클리어 기준 정보는 UI에 노출 안 함

## 페이지 3 — 피드백

### 레이아웃
```
상단
  - 클리어 여부
  - 총 이해도 (숫자 %)

발화별 카드 (최대 5개 반복)
  Q. 외국인 질문
  A. 내 답변 (두 줄 이상 더보기 처리)
  - 이해도: n%
  - 외국인 귀에 이렇게 들렸어요
  - 더 나은 표현 + n% 이해도 상승
  - 발화 시간: n초

하단
  - 나가기 버튼 → 시나리오 선택 페이지
```
